What I Did in Week 1

In Week 1, I started building my web programming portfolio and learned how a web application works from the browser to the server. The main goal was to create a Flask page, put the project under version control, publish it on GitHub, and deploy it so that it could be accessed online.

1. Set Up My Development Environment

I prepared the tools needed for the project, including Visual Studio Code, Python, and Git. I also created a Python virtual environment so that the project could use its own dependencies separately from the rest of my computer.

2. Created and Ran My First Flask Page

I used the starter project and created a Flask web application. I installed the required dependencies and ran the application locally using Flask. I then opened the local site in my browser and changed the heading to include my name.

The local application was tested with the Flask development server before moving on to deployment.

3. Used Git and GitHub

I initialized Git in the project, added my files, and created a commit for the Week 1 portfolio home page. I then created a public GitHub repository for the project and pushed my code to it.

My GitHub repository: View my GitHub repository

4. Deployed the Website with Render

After pushing the project to GitHub, I connected the repository to Render and deployed the Flask application. This gave my website a public URL instead of keeping it available only on my computer.

I also verified the deployed page in a browser to make sure the live application was working correctly.

My live Render website: View my live website

5. What I Learned

Week 1 helped me understand the difference between the Internet and the World Wide Web, the client-server model, and the request-response cycle. I also learned the basic role of HTTP, DNS, Git, GitHub, Flask, and Render in a web application.

6. My Week 1 Result

By the end of the week, I had the starting version of my portfolio website running with Flask, stored in GitHub, and deployed online. This became the foundation for the new pages and features I will add during the following weeks.
