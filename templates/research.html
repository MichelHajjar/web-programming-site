1. CSS At-Rules

What is CSS at-rules?

An at-rule is a CSS statement that begins with the at sign (@), followed by an identifier such as media, supports, import, or keyframes. At-rules give instructions to the CSS processor rather than directly selecting an HTML element in the same way that an ordinary CSS rule does.

Major CSS at-rules

At-rule Main purpose Category
@media Responsive and conditional styling based on the device/environment Conditional at-rules
@supports Apply styles only when a browser supports a CSS feature
@container Apply styles according to the size/state of a containing element
@import Import another CSS stylesheet Resource/import and descriptive at-rules
@font-face Define a custom web font
@keyframes Define the stages of a CSS animation Animation and visual behavior
@layer Organize CSS into cascade layers Cascade and organization
@scope Restrict CSS rules to a specific DOM subtree
@page Control the appearance of printed pages Printing
@property Register and define a typed CSS custom property Advanced CSS / custom properties

2. Regular Expressions

What is a Regular Expression?

A regular expression, often shortened to regex or regexp, is a pattern used to describe and match specific combinations of characters in text. Developers can use these patterns to determine whether text follows a particular format, find parts of a string, extract information, replace text, or split text.


Common Regex Symbols

Symbol Meaning Example
. Any character except newline in the default mode a.c
^ Beginning of a string/line ^Hello

[abc] One character from the set [abc]
[^abc] One character not in the set [^abc]
\d A digit \d
\D A non-digit \D

{n,m} Between n and m repetitions \d{2,4}
| OR cat|dog

Why Are Regular Expressions Useful?

Regular expressions are useful because they can:

  • Describe complex text formats concisely.
  • Validate structured input.
  • Search large amounts of text.
  • Extract information.
  • Replace repeated patterns.
  • Process strings efficiently in many situations.

They are especially valuable when the structure of the data can be described clearly as a pattern. Python's documentation also notes that regular expressions can become difficult to understand when the task becomes too complicated.

3. <button> vs <input type="button">

What is the difference?

Both elements can create a clickable button, but they are different HTML elements with different capabilities.

The <button> element

The <button> is a dedicated HTML button element and it is a general-purpose interactive element.

<button type="button">Click Me</button>

The text Click Me is placed between the opening and closing tags. One of its biggest advantages is that its content can contain HTML and with <button>, it is easier to style and can contain HTML content such as images.

The <input type="button"> element

With <input type="button">, the button's visible label comes from the value attribute.

<input type="button" value="Click Me">

The <input> element is a void element, meaning it does not have a closing tag and cannot contain child HTML.

Summary

<button> is more flexible because it can contain text, images, and other permitted HTML content. <input type="button"> is simpler and uses its value attribute as its label. Both can be styled with CSS and controlled with JavaScript, but <button> is generally preferred for modern web development.

4. <datalist> vs. <select>

What is <datalist>?

<datalist> provides a set of suggested values for another form control, usually an <input>. It does not create the input field itself. The input remains editable, and the user can normally enter a value that is not included in the suggestions.

What is <select>?

<select> creates an actual selection control containing predefined options. The user selects from the available <option> elements rather than using the control as a free-text input.

Conclusion

<select> and <datalist> both provide predefined options, but they serve different purposes. <select> is a form control used when the user must choose from a defined list of options. <datalist> provides suggestions for an associated input while still allowing the user to enter another value. Therefore, <select> is more appropriate for fixed choices, while <datalist> is useful when suggestions can help the user without restricting their input.

5. JavaScript vs. JScript vs. ECMAScript

1. What is JavaScript?

JavaScript (JS) is a programming language widely used to make web pages interactive and dynamic. It can respond to user actions, manipulate HTML through the DOM, communicate with servers, create animations, and much more. It is also used outside browsers, for example with Node.js.

For example:

const button = document.querySelector("#myButton");

button.addEventListener("click", function () {
    alert("Hello!");
});

This JavaScript waits for a button click and then displays a message.

2. What is ECMAScript?

ECMAScript is the standardized specification for the language.

The specification defines things such as:

  • syntax;
  • variables;
  • data types;
  • operators;
  • functions;
  • objects;
  • control structures;
  • modules;
  • built-in objects and functions;
  • error handling;
  • language semantics.

The standard is maintained by Ecma International's Technical Committee 39 (TC39).The official standard is called ECMA-262. The current published edition is ECMAScript 2026, 17th edition, published in June 2026.

3. What is JScript?

JScript was Microsoft's implementation/dialect of ECMAScript.

Microsoft's documentation explicitly describes JScript 5.x as a dialect of ECMAScript and says that it was based on the ECMAScript specification.

JScript was strongly associated with Microsoft Internet Explorer.

4. Why was JScript created?

JavaScript was developed at Netscape, while Microsoft developed its own implementation for Internet Explorer. Microsoft called its implementation JScript rather than JavaScript. As different browser vendors implemented scripting languages, there was a need for a common standard. That led to the standardization work that became ECMAScript.

According to Ecma's history and the ECMAScript specification:

  • JavaScript was created at Netscape;
  • JScript was Microsoft's scripting language;
  • standardization began in 1996;
  • the first ECMAScript edition was adopted in June 1997;
  • the standard was subsequently approved by ISO as ISO/IEC 16262.

6. Conclusion

JavaScript, JScript, and ECMAScript are related but have different meanings. ECMAScript is the standardized specification that defines the core scripting language. JavaScript is the name commonly used for the language and its implementations, especially on the Web. JScript was Microsoft's implementation/dialect of ECMAScript and was historically used with Internet Explorer. Modern web development primarily uses JavaScript implementations that follow current ECMAScript standards.

6. Automatic Function Invocation

What is Automatic Function Invocation?

In JavaScript, a function normally runs when it is called. However, a function can also be invoked automatically when a specific event or condition occurs, such as when a web page finishes loading or when the user clicks a button. This is commonly done by passing the function to an event listener.

Example:

function sayHello() {
    alert("Hello!");
}

document.addEventListener("DOMContentLoaded", sayHello);

In this example, sayHello is not called directly with sayHello(). Instead, it is given to the DOMContentLoaded event. The browser automatically invokes the function when the HTML document has finished loading.

This approach is useful for initializing a webpage and responding to user actions.
