Introduction

The World Wide Web began in 1989 when Tim Berners-Lee, a researcher at CERN, proposed a better way for scientists to share and link information using hypertext. To make his idea work, he built the core technologies that still power the Web today: HTML, HTTP, and URLs. After launching the first website and web browser from CERN, the technology was released to the public for free. This ultimately transformed the Web into the primary way people navigate and share information across the globe.

Timeline

1. The World Wide Web is Proposed (1989)

Tim Berners-Lee proposed a system for sharing information between researchers at CERN using hypertext. This proposal became the foundation of the World Wide Web and introduced the basic idea of linking documents together.

Source: CERN

2. HTML, HTTP, and URLs Developed (1990)

Tim Berners-Lee developed the main technologies needed for the Web, including HTML for creating web documents, HTTP for communication between browsers and servers, and URLs for identifying resources. These technologies formed the basic structure of the Web and allowed documents to be created, connected, and accessed.

Source: W3C — History of the Web

3. First Web Server and Web Browser (1990)

Tim Berners-Lee created the first Web server and the first Web browser at CERN. The browser was originally called World Wide Web. The Web became a working system rather than just an idea. Users could create and view hypertext documents through the browser.

Source: W3C — History of the Web

4. First Website Becomes Available (1991)

The first website was made available at CERN. It explained what the World Wide Web was and how people could use it. This marked the beginning of the Web as a working information system that other people could access. The exact date of the first website's public availability is sometimes reported differently. CERN identifies 1991 as the year the first website went live.

Source: CERN

5. Web Becomes Publicly Available (1993)

Date: April 30, 1993.

CERN released the World Wide Web software into the public domain and made it freely available. Removing licensing restrictions allowed anyone to use and develop the Web without paying CERN. This greatly helped the Web spread.

Source: CERN

6. Mosaic Web Browser Released (1993)

The Mosaic graphical web browser was developed at the National Center for Supercomputing Applications (NCSA) at the University of Illinois. Mosaic made the Web easier to use by providing a graphical interface and displaying text and images together. It helped increase the Web's popularity.

Source: National Center for Supercomputing Applications, University of Illinois

7. Web Standards Continue to Develop (1995)

W3C and other organizations continued developing standards for HTML, HTTP, and other Web technologies as the Web rapidly expanded. Common standards helped maintain compatibility between different browsers and websites and supported the continued growth of the Web.

Source: W3C

8. Web 2.0 Becomes Popular(2004)

The term “Web 2.0” became widely used after the first Web 2.0 Conference. It described a shift toward a more interactive Web, where users could create and share content through blogs, wikis, social networks, and other interactive websites. This marked an important change from the earlier Web, where users were mainly consumers of information.

source: Computer History Museum

9. HTML5 Becomes a W3C Recommendation(2014)

The World Wide Web Consortium (W3C) published HTML5 as an official Recommendation. HTML5 introduced important capabilities for modern Web pages and applications, including native audio and video, graphics, and improved support across different devices. It became an important foundation for the modern Web.

source: W3C — HTML5 Recommendation

10. HTTP/3 Becomes an Internet Standard(2022)

HTTP/3 was published as an official Internet standard by the IETF. HTTP is one of the main protocols used by Web browsers and Web servers to communicate. HTTP/3 uses QUIC to improve the performance and reliability of Web connections, making it an important development in the modern Web.

source: RFC Editor - RFC 9114 (HTTP/3)

Three Key Technologies

1. HTML (HyperText Markup Language)

Created by Tim Berners-Lee around 1990 during the birth of the World Wide Web, HTML is the standard markup language used to structure content on web pages. It allowed creators to organize raw information into formatted documents using headings, text blocks, and embedded links. By serving as the fundamental building block for website design, HTML established the basic language for building web pages across the internet.

2. HTTP (HyperText Transfer Protocol)

Developed alongside the Web in 1990, HTTP functions as the communication protocol that connects web browsers to web servers. It defines the rules for how data is transmitted across the internet, allowing a user's browser to send requests to a server and retrieve resources in return. Without HTTP, there would be no reliable protocol for fetching and loading web pages when navigating online.

3. URLs (Uniform Resource Locators)

Introduced around 1990 as part of the Web's original framework, a URL acts as a unique web address that identifies and locates specific resources on the network. By assigning distinct paths to individual files, pages, and documents, URLs made cross-linking across different servers possible. They remain an essential mechanism for navigating the web, allowing users to jump directly to any resource with a simple web address.
